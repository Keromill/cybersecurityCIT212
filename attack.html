Common Attacks

Phishing Attacks

Phishing attacks are extremely common and hundreds are sent out daily. They are malicious emails/impersonations that are designed to look trustworthy and trick the user into giving up sensitive information or money.

Denial-Of-Service (DoS) Attacks

These attacks work by overwhelming a site/system's resources by requesting so many to the point where it is no longer able to function and operate for genuine users. A Distributed Denial-Of-Service (DDoS) attack is the same idea of denying user's the service, but on a much larger scale using multiple infected devices.

Man-In-The-Middle (MITM) Attacks

These attacks work with the attacker acting as a malicious agent between two people/devices. By doing so this attacker can spy on all of the communications occuring or even modify it to perform another attack.

SQL Injection

SQL attacks are a very important one to be weary of as they are a great risk to websites utilizing databases for user data. An attacker will push malicious SQL queries into the database, and the database might run that attack just trying to retrieve the user information/request. This can cause data leaks, modification, deletion, or even administrative functions to disrupt the database.

Brute Force

This attack is as described, where the attacker forcibly tries over and over to guess the credentials to access an account or website. These often use automated bots to do this.

XSS/Cross-site Scripting Attacks

An attacker places malicious scripts into content that is clickable on a web page. If a user clicks this malicious element then the script is executed and because the user is likely already logged into the site these scripts will be seen as legitmate. This means it may appear as the user doing the action when really it's an attacker, like withdrawing money from an account.
